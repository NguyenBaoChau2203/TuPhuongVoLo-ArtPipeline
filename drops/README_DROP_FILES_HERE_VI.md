# 📁 Thư mục nhận file — drops/

## Cách sử dụng

**Bỏ file vào đây** để pipeline xử lý tự động.

### File được chấp nhận:
- `.svg` — File SVG từ Illustrator
- `.png` — Ảnh tham khảo
- `.ai` — File Illustrator (sẽ được sao chép, không sửa đổi)

### Sau khi xử lý:
- File sẽ được **sao chép** (không xóa) vào thư mục phù hợp trong `assets/`
- File gốc trong `drops/` **vẫn giữ nguyên**
- Bạn có thể xóa file trong `drops/` sau khi xác nhận kết quả OK

### Kết quả:
- Xem ở thư mục `outputs/`
- Hoặc chạy `launchers/05_open_outputs.bat`

---

⚠️ **Lưu ý**: Không bỏ file quá lớn (>100MB) vào đây.
⚠️ **Lưu ý**: Đặt tên file bằng tiếng Anh không dấu, không khoảng trắng.
