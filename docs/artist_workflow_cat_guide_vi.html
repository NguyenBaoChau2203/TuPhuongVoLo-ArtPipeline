Từ ảnh mẫu sang JSX Draft

reference_to_layout_draft.jsx là gì?

Đây là khuôn JSX cho Illustrator. Codex không bắt vợ vẽ từ trang trắng; Codex sẽ nhìn ảnh mẫu và mô tả, rồi tạo một file JSX riêng dựa trên khuôn này.

Khi chạy JSX trong Illustrator, nó tạo sẵn các layer/group có tên đúng pipeline: room_, door_, window_, prop_, flow_. Vợ chỉ cần sửa dáng, kéo vị trí, thêm/bớt chi tiết theo mắt nhìn rồi xuất SVG thủ công.

✅ JSX có thể làm sẵn: ranh phòng/map, cửa/cửa sổ, vị trí đồ lớn, flow di chuyển, vài shape chính, tên layer/group theo pipeline.
⚠️ JSX không nên xuất SVG tự động. Bước export vẫn để vợ làm sau khi review trong Illustrator, vì mắt họa sĩ quyết định bố cục cuối tốt hơn automation.

Cách gửi ảnh cho Codex

  1. Gửi ảnh mẫu hoặc ảnh chụp màn hình bố cục.
  2. Gửi mô tả ngắn bằng tiếng Việt: phòng gì, mood gì, đồ lớn nào cần có.
  3. Nói rõ tên asset và tên room/layer muốn dùng, ví dụ phong_kho.
  4. Yêu cầu Codex tạo file JSX dựa trên template scripts/illustrator/templates/reference_to_layout_draft.jsx.
  5. Mở Illustrator → File → Scripts → Other Script... → chọn file JSX Codex tạo.
  6. Vợ chỉnh lại layout trong Illustrator rồi export SVG sạch vào drops/.
Hãy nhìn ảnh mẫu này và tạo Illustrator JSX draft cho pipeline Tứ Phương Vô Lộ. Cần có: - room boundary khép kín - cửa chính và cửa sổ nếu thấy trong ảnh - prop lớn: kệ, bàn, thùng, giường hoặc đồ lớn tương ứng ảnh - flow di chuyển chính - layer/group đặt tên đúng pipeline: room_, door_, window_, prop_, flow_ Dùng template: scripts/illustrator/templates/reference_to_layout_draft.jsx Không export SVG tự động. Chỉ tạo JSX an toàn, editable, để vợ tôi review rồi export SVG thủ công.

Quy tắc vẽ trong Illustrator

  • 📁 Mỗi phòng nên nằm trong group hoặc layer riêng. Pipeline đọc tên group/layer để nhận diện phòng.
  • 🏷️ Đặt tên group/layer rõ ràng, không dấu, không khoảng trắng: ví dụ phong_kho, phong_bep, phong_ngu, sanh_chinh.
  • 🔒 Đường bao phòng phải đóng kín — không để hở góc tường hay nối thiếu điểm cuối.
  • 📐 Ưu tiên tường bằng đường thẳng và path đơn giản. Tránh freehand quá cong phức tạp cho vùng tường chính.
  • 🚫 Không ghi đè file .ai gốc. Luôn xuất SVG riêng ra thư mục khác.
  • 📤 Xuất SVG sạch sang thư mục bên ngoài thư mục assets/ — ví dụ: bỏ vào drops/ trước khi chạy app.
⚠️ File .ai gốc không được phép bị ghi đè hoặc xóa bởi bất kỳ bước nào trong pipeline. Nếu app hỏi chọn file SVG, chỉ chọn file .svg đã xuất riêng.

Quy ước đặt tên

Tên phòng

Tên phòng phải viết thường, không dấu, dùng dấu gạch dưới. Pipeline dùng tên phòng để đặt tên cảnh Maya và tên output file.

phong_kho phong_bep phong_ngu sanh_chinh phong_tam hanh_lang

🐾 Bộ marker prop cho Illustrator

Prop marker là group/layer nhỏ đặt bên trong group phòng để nói với pipeline: “ở đây có một món đồ cần dựng blockout”. Tên marker quan trọng vì pipeline đọc tên group/layer, không hiểu toàn bộ nét vẽ freehand của đồ nội thất.

🐱 Mở SVG mẫu tại assets/2d/templates/illustrator_prop_marker_template.svg, copy marker cần dùng, paste vào group phòng thật, rồi di chuyển/scale trong Illustrator.
  1. Mở template SVG trong Illustrator.
  2. Copy một group marker, ví dụ prop_bed.
  3. Paste marker vào group phòng thật, ví dụ phong_kho.
  4. Di chuyển/scale marker để tâm marker nằm đúng vị trí đặt prop; kích thước marker chỉ là gợi ý footprint an toàn.
  5. Xuất SVG sạch, mở desktop app, chạy dry-run trước.
  6. Đọc danh sách Prop marker SVG trong log dry-run.
  7. Khi dry-run đúng, bỏ dry-run và chạy Maya build thật.

Tên canonical nên dùng

prop_bed prop_table prop_chair prop_sofa prop_fridge prop_sink prop_kitchen_counter prop_cabinet prop_locker prop_plant prop_shelf_unit prop_wooden_crate

Alias dùng được nhưng tên canonical vẫn nên ưu tiên: prop_desk → table, prop_couch → sofa, prop_refrigerator → fridge, prop_counter → kitchen_counter, prop_cupboard → cabinet, prop_potted_plant → plant, prop_shelf/prop_shelving → shelf_unit, prop_crate/prop_box → wooden_crate.

  • ✅Tên marker viết lowercase ASCII, dùng dấu gạch dưới, bắt đầu bằng prop_.
  • ✅Không dùng khoảng trắng, dấu tiếng Việt, dấu câu, emoji, hoặc ký tự trang trí trong tên group/layer.
  • ✅Trong group marker, dùng shape đơn giản như rect, polygon, polyline, hoặc path thẳng.
⚠️ Pipeline hiện chưa hiểu đầy đủ mọi nét vẽ nội thất tự do. Prop tạo ra là blockout để kiểm tra bố cục, chưa phải model cuối cùng. Họa sĩ vẫn polish/thay prop trong Maya. Feature 006 điều khiển bằng ngôn ngữ tự nhiên chưa nằm trong workflow này.

Nếu tên prop chưa được hỗ trợ, Maya vẫn tạo cube placeholder đơn giản thay vì dừng pipeline. Fixture tests/in/illustrator_prop_showcase.svg dùng để kiểm tra kỹ thuật nhiều loại prop; template mới là file copy/paste cho Illustrator.

Cách dùng Desktop App

🐱 Cách ưu tiên nhất: Double-click vào launchers/09_artist_desktop_app.bat để mở app. Không cần mở terminal hay nhập lệnh.
  1. Mở launchers/09_artist_desktop_app.bat (double-click).
  2. Bấm Chọn SVG để chọn file SVG sạch đã xuất từ Illustrator.
  3. Nhập Tên phòng, ví dụ: phong_kho.
  4. Bấm Kiểm tra SVG, rồi bấm Chạy thử an toàn cho lần chạy đầu tiên.
  5. Bật Render PNG preview nếu muốn xem ảnh kiểm tra nhanh.
  6. Kiểm tra Repo root và Command preview hiển thị đúng trong app.
  7. Đọc log bên dưới — dry-run không tạo file thật.
  8. Nếu log dry-run trả exit code 0 và lệnh trông đúng → chuyển sang bước dựng thật.
  9. Kiểm tra đường dẫn mayapy.exe (ví dụ: C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe).
  10. Bấm Dựng Maya thật để tạo file .ma.
  11. Bấm Tự tìm output mới nhất để app điền file .ma và geometry JSON vừa sinh ra.
  12. Bấm Tạo Visual Fidelity nếu muốn thêm lớp dễ đọc trước khi polish.
  13. Bấm Tạo Maya Sandbox, rồi bấm Mở working/scene_agent_work.ma để mở bản sandbox trong Maya.
📂 App có nút tắt để mở nhanh: outputs/maya/, outputs/preview/, outputs/reports/, repo, và sandbox working scene mới nhất. Dùng các nút này để không phải tìm file thủ công.

Maya Sandbox + script polish

✅ Đây là bước hỗ trợ phần Maya sau khi đã có SVG và file .ma. Codex có thể viết script Maya Python để thêm chi tiết, ánh sáng, camera, prop phụ, vật liệu nháp vào một group riêng để vợ review.

agent_polish_additive_template.py là gì?

Đây là khuôn script Maya Python an toàn. Codex sẽ copy khuôn này và chỉnh thành script riêng cho từng cảnh, ví dụ: thêm kệ, thùng, đèn ấm, camera review, hoặc vài chi tiết giúp blockout dễ đọc hơn.

Script này chỉ được chạy trong sandbox working/scene_agent_work.ma. Nó tạo mọi thứ mới dưới một group riêng như GRP_agent_polish_v001, nên vợ có thể hide group, delete group, hoặc rollback sandbox nếu không thích.

⚠️ Không chạy script polish trực tiếp trên file gốc trong outputs/maya/. Luôn tạo sandbox trước, mở file working/scene_agent_work.ma, rồi mới chạy script Codex gửi.

Cách dùng hằng ngày sau khi có file .ma

  1. Desktop App tạo xong file .ma trong outputs/maya/.
  2. Bấm Tự tìm output mới nhất để app điền scene và geometry JSON.
  3. Bấm Tạo Maya Sandbox để có bản làm việc working/scene_agent_work.ma và backup.
  4. Bấm Mở working/scene_agent_work.ma để mở sandbox trong Maya.
  5. Gửi ảnh preview hoặc mô tả cho Codex: muốn thêm gì, bỏ gì, mood ánh sáng ra sao.
  6. Codex tạo script dựa trên scripts/maya/agent_polish_templates/agent_polish_additive_template.py.
  7. Trong Maya: mở Script Editor, dán script Python, chạy.
  8. Vợ review group GRP_agent_polish_v001: bật/tắt, sửa tay, xóa group, hoặc rollback sandbox nếu không thích.

Prompt mẫu gửi Codex cho Maya polish

Hãy tạo Maya Python polish script cho sandbox hiện tại. Scene đang mở phải là: working/scene_agent_work.ma Dùng template: scripts/maya/agent_polish_templates/agent_polish_additive_template.py Yêu cầu: - không sửa/xóa tường, cửa, layout gốc - tạo mọi object mới dưới group GRP_agent_polish_v001 - thêm các chi tiết sau: [mô tả đồ vật / ánh sáng / camera / mood] - đặt tên object rõ ràng bằng ASCII - nếu không thích, vợ tôi có thể hide/delete group hoặc rollback sandbox Hãy trả về script Python để dán vào Maya Script Editor.

Từ điển nhỏ 🐾

SVG sạch

File SVG đã được xuất đúng cách từ Illustrator — không có layer ẩn rác, không có metadata thừa. Đây là file bạn nạp vào app.

Boundary

Đường bao phòng — path khép kín xác định ranh giới tường/sàn của một phòng. Pipeline đọc boundary để dựng blockout.

Prop marker

Group/layer trong Illustrator có tên bắt đầu bằng prop_ (hoặc item_, object_). Pipeline đọc tên để tạo blockout đồ vật trong Maya; tên lạ sẽ về cube placeholder đơn giản.

Blockout

Khung 3D cơ bản — tường, sàn, prop blockout dễ nhận ra nhưng vẫn đơn giản — được tạo tự động. Họa sĩ polish lại blockout này trong Maya.

Polish

Bước chỉnh tay cuối cùng trong Maya — thêm chi tiết, ánh sáng, vật liệu, animation, và mọi thứ mà pipeline tự động không làm được.

Dry-run

Chế độ "thử không làm thật" — app in lệnh sẽ chạy và kiểm tra logic, nhưng không tạo file Maya thật. Luôn dry-run trước.

mayapy

Chương trình Python của Autodesk Maya dùng để chạy script tạo cảnh .ma. Đường dẫn thường là C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe.

JSX Draft

Script Illustrator do Codex tạo từ ảnh mẫu và mô tả. Khi chạy, nó dựng sẵn layout vector editable để họa sĩ chỉnh tiếp rồi export SVG thủ công.

Maya sandbox

Bản copy an toàn của cảnh Maya dùng để thử script polish. Nếu không thích kết quả, có thể hide/delete group agent hoặc rollback sandbox.

Giải thích từng bước trong Maya Artist App

💡 Phần này giải thích từng trường, từng nút bấm, từng ô checkbox trong app. Hữu ích nhất khi bạn mở app lần đầu và không chắc mỗi ô có nghĩa gì.

🐾 Step 1: Chọn bản vẽ SVG

Đây là bước bạn nói với app: "Tôi muốn xử lý file SVG nào và tên phòng là gì."

Tên trường Ý nghĩa & cách dùng
File SVG sạch Đường dẫn đến file SVG đã xuất từ Illustrator. Ví dụ: assets/2d/svg_clean/phong_kho.svg. Không chọn file .ai gốc — phải là .svg đã xuất riêng.
Nút Chọn SVG Mở hộp thoại chọn file. Duyệt đến file .svg sạch và bấm OK.
Tên phòng/layer Tên group hoặc layer trong Illustrator tương ứng với phòng cần dựng. Ví dụ: phong_kho, phong_bep, phong_ngu, phong_marker_template. Phải trùng với tên group/layer thật trong file SVG.
Repo root Thư mục gốc của dự án — app tự tìm, bạn thường không cần sửa. Chỉ đọc.

🏠 Step 2: Dựng Maya blockout

Đây là bước cốt lõi — cấu hình và chạy pipeline để tạo file .ma blockout trong Maya.

Tên trường / nút Ý nghĩa & cách dùng
Thư mục output Nơi lưu kết quả. Mặc định là outputs. Bên trong sẽ có:
• outputs/maya/ → file .ma
• outputs/preview/ → ảnh PNG preview
• outputs/reports/ → báo cáo
mayapy.exe Đường dẫn đến chương trình Python của Maya. Ví dụ: C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe. Chỉ cần điền khi chạy thật (Dry-run tắt). Không cần cho dry-run.
☑ Dry-run Giữ BẬT khi mới bắt đầu. Dry-run kiểm tra lệnh và xem danh sách prop marker, nhưng KHÔNG tạo file .ma thật, KHÔNG ghi manifest. An toàn để thử bao nhiêu lần cũng được.
☐ Render PNG preview Nếu bật, sau khi chạy Maya thật, pipeline cũng tạo ảnh PNG preview trong outputs/preview/. Tùy chọn, không bắt buộc.
Render width / height Kích thước ảnh PNG preview tính bằng pixel. Mặc định 1280 × 720 là đủ dùng. Chỉ dùng khi Render PNG preview được bật.
🟠 Chạy pipeline Nút chính — quan trọng nhất. Chạy pipeline theo cấu hình hiện tại. Nếu Dry-run bật: chỉ kiểm tra. Nếu Dry-run tắt: tạo file .ma thật. Đọc log ngay sau khi bấm.
Xóa log Xóa nội dung vùng log để dễ đọc kết quả mới. Không ảnh hưởng đến file thật nào.

Mở outputs/maya Mở thư mục chứa file .ma vừa tạo trong File Explorer. Mở file .ma này trong Maya để polish.

🐱 Quy trình dùng SVG mẫu marker:
1. Bấm Mở SVG mẫu marker → mở trong Illustrator.
2. Chọn và copy một group marker, ví dụ prop_bed.
3. Paste vào group phòng thật trong Illustrator (ví dụ: phong_kho).
4. Di chuyển/scale marker sao cho tâm nằm đúng vị trí đặt prop.
5. Xuất lại SVG sạch từ Illustrator.
6. Chọn file SVG mới trong app → chạy dry-run trước.
7. Đọc log để xác nhận danh sách prop marker đúng.
8. Khi OK, tắt Dry-run và chạy thật.
