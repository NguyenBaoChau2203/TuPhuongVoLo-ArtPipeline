Quy tắc vẽ trong Illustrator

  • 📁 Mỗi phòng nên nằm trong group hoặc layer riêng. Pipeline đọc tên group/layer để nhận diện phòng.
  • 🏷️ Đặt tên group/layer rõ ràng, không dấu, không khoảng trắng: ví dụ phong_kho, phong_bep, phong_ngu, sanh_chinh.
  • 🔒 Đường bao phòng phải đóng kín — không để hở góc tường hay nối thiếu điểm cuối.
  • 📐 Ưu tiên tường bằng đường thẳng và path đơn giản. Tránh freehand quá cong phức tạp cho vùng tường chính.
  • 🚫 Không ghi đè file .ai gốc. Luôn xuất SVG riêng ra thư mục khác.
  • 📤 Xuất SVG sạch sang thư mục bên ngoài thư mục assets/ — ví dụ: bỏ vào drops/ trước khi chạy app.
⚠️ File .ai gốc không được phép bị ghi đè hoặc xóa bởi bất kỳ bước nào trong pipeline. Nếu app hỏi chọn file SVG, chỉ chọn file .svg đã xuất riêng.
🏷️

Quy ước đặt tên

Tên phòng

Tên phòng phải viết thường, không dấu, dùng dấu gạch dưới. Pipeline dùng tên phòng để đặt tên cảnh Maya và tên output file.

phong_kho phong_bep phong_ngu sanh_chinh phong_tam hanh_lang

Marker cho đồ vật / prop

Trong Illustrator, đặt tên group/layer cho các đồ vật theo tiền tố prop_ (hoặc item_ / object_). Pipeline đọc tên này để tạo blockout đồ vật dễ nhận ra hơn trong cảnh Maya.

🐱 Pipeline đọc tên group/layer — không đọc từ nội dung vẽ bên trong. Đặt tên đúng là bước quan trọng nhất!
prop_bed prop_table prop_chair prop_sofa prop_fridge prop_sink prop_kitchen_counter prop_cabinet prop_locker prop_plant prop_shelf_unit prop_wooden_crate

Alias an toàn cũng dùng được: desk → table, couch → sofa, refrigerator → fridge, counter → kitchen_counter, cupboard → cabinet, potted_plant → plant, shelf/shelving → shelf_unit, crate/box → wooden_crate.

Nếu tên prop chưa được hỗ trợ, Maya vẫn tạo cube placeholder đơn giản. Marker bên trong group nên là rect, polygon, polyline, hoặc path thẳng; blockout vẫn là draft để polish/thay model thật trong Maya.

Định dạng tên file output

Mọi output được tạo ra sẽ tự động theo mẫu:

tu_phuong_vo_lo_{tên_asset}_{variant}_{stage}_v{version}

Họa sĩ không cần nhớ định dạng này — pipeline tự xử lý khi chạy.

Công cụ hiểu gì — chưa hiểu gì

✅ Hiểu được ngay bây giờ
  • Đường bao phòng (room boundary)
  • Tên phòng từ group/layer
  • Các shape SVG cơ bản được hỗ trợ
  • Prop marker theo tên group/layer
  • Tạo file .ma blockout trong Maya
  • Tạo ảnh PNG preview
  • AI preview từ PNG (tùy chọn, tham khảo)
🚧 Chưa hiểu đầy đủ
  • Toàn bộ nét vẽ freehand của đồ vật
  • Line art chi tiết của nội thất
  • Tự tạo cảnh isometric final đã polish
  • Điều khiển bằng lệnh tự nhiên (Feature 006 — chưa làm)
💡 Pipeline tạo ra blockout kỹ thuật — khung 3D cơ bản cho họa sĩ polish tiếp. Đây là bước trung gian, không phải final art tự động.

Cách dùng Desktop App

🐱 Cách ưu tiên nhất: Double-click vào launchers/09_artist_desktop_app.bat để mở app. Không cần mở terminal hay nhập lệnh.
  1. Mở launchers/09_artist_desktop_app.bat (double-click).
  2. Bấm Browse để chọn file SVG sạch đã xuất từ Illustrator.
  3. Nhập Tên phòng, ví dụ: phong_kho.
  4. Giữ Dry-run ở trạng thái bật cho lần chạy đầu tiên.
  5. Bật Render PNG preview nếu muốn xem ảnh kiểm tra nhanh.
  6. Kiểm tra Repo root và Command preview hiển thị đúng trong app.
  7. Bấm Chạy pipeline và đọc log bên dưới — dry-run không tạo file thật.
  8. Nếu log dry-run trả exit code 0 và lệnh trông đúng → bỏ chọn Dry-run.
  9. Kiểm tra đường dẫn mayapy.exe (ví dụ: C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe).
  10. Bấm Chạy pipeline lần nữa để tạo file .ma thật.
  11. Mở thư mục outputs/maya/ để lấy file .ma và mở trong Maya để polish.
📂 App có nút tắt để mở nhanh: outputs/maya/, outputs/preview/, và thư mục repo. Dùng nút này để tìm file output mà không cần tìm thủ công.
🤖

AI Preview — tùy chọn, tham khảo thôi không bắt buộc

⚠️ AI Preview không tự chạy sau khi Maya sinh ra file. Đây là tính năng riêng biệt — họa sĩ phải tự chọn PNG và bấm nút riêng.

Dùng AI Preview với mock (không cần API key)

  1. Sau khi Maya tạo xong ảnh preview, chuyển sang khu vực AI polish preview trong app.
  2. Chọn file PNG preview đã tạo (thường trong outputs/preview/).
  3. Chọn Provider: mock — không cần API key, không cần internet.
  4. Giữ AI dry-run bật cho lần đầu để chỉ xem kế hoạch.
  5. Bấm Tạo AI polish preview và đọc log.
  6. Nếu muốn xem ảnh mock thật, tắt AI dry-run rồi bấm lại.
  7. Ảnh output nằm trong outputs/ai_preview/.

Về provider fal tùy chọn nâng cao

  • 🔑 Provider fal chỉ hoạt động khi máy đã cài fal-client và đặt biến môi trường FAL_KEY. Không cần làm bước này cho workflow bình thường.
  • 🛡️ Nếu thiếu FAL_KEY và bật Bỏ qua nếu thiếu cấu hình AI, pipeline Maya vẫn chạy bình thường — AI chỉ skip an toàn.
  • 📌 Ảnh AI chỉ là tham khảo mood, ánh sáng, vật liệu. File .ma vẫn là nguồn để polish cuối trong Maya.
🛡️

Danh sách an toàn

⚠️ Những điều KHÔNG được làm
  • 🚫 Không xóa hoặc ghi đè file .ai gốc bằng bất kỳ bước nào.
  • 🚫 Không commit các file trong outputs/ lên Git — đây là output tạm thời.
  • 🚫 Không chạy thật trước khi dry-run trả exit code 0.
  • 🚫 Không xóa file .ma trong outputs/maya/ khi đang polish trong Maya — đó là nguồn chỉnh sửa.
  • 🚫 Nếu không chắc bước nào — dừng lại và hỏi dev/operator.
✅ Những điều NÊN làm
  • ✅ Luôn chạy dry-run trước khi chạy thật.
  • ✅ Giữ file .ai gốc trong thư mục riêng, chỉ xuất SVG riêng để dùng với pipeline.
  • ✅ File .ma là nguồn editable chính — polish trong Maya, không sửa file SVG từ bước Maya.
  • ✅ Đọc log trong app sau mỗi bước — log bằng tiếng Việt và sẽ thông báo lỗi rõ ràng.
  • ✅ Nếu app báo lỗi về Python hoặc repo — chạy từ thư mục repo hoặc dùng launcher .bat.

Từ điển nhỏ 🐾

SVG sạch

File SVG đã được xuất đúng cách từ Illustrator — không có layer ẩn rác, không có metadata thừa. Đây là file bạn nạp vào app.

Boundary

Đường bao phòng — path khép kín xác định ranh giới tường/sàn của một phòng. Pipeline đọc boundary để dựng blockout.

Prop marker

Group/layer trong Illustrator có tên bắt đầu bằng prop_ (hoặc item_, object_). Pipeline đọc tên để tạo blockout đồ vật trong Maya; tên lạ sẽ về cube placeholder đơn giản.

Blockout

Khung 3D cơ bản — tường, sàn, prop blockout dễ nhận ra nhưng vẫn đơn giản — được tạo tự động. Họa sĩ polish lại blockout này trong Maya.

Polish

Bước chỉnh tay cuối cùng trong Maya — thêm chi tiết, ánh sáng, vật liệu, animation, và mọi thứ mà pipeline tự động không làm được.

Dry-run

Chế độ "thử không làm thật" — app in lệnh sẽ chạy và kiểm tra logic, nhưng không tạo file Maya thật. Luôn dry-run trước.

mayapy

Chương trình Python của Autodesk Maya dùng để chạy script tạo cảnh .ma. Đường dẫn thường là C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe.

AI preview

Ảnh tham khảo được tạo bởi AI từ PNG preview. Chỉ dùng để xem mood / cảm hứng — không thay thế file .ma để polish.
